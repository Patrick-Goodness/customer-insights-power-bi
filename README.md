# Customer Insights Dashboard — Power BI

## Project Overview

The Customer Insights Dashboard is an interactive Power BI project designed to analyse customer demographics, customer segments, occupations, regional distribution, gender composition, age groups, and customer trends over time.

## Business Objective

The objective is to provide a clear view of the customer base and support practical questions around regional distribution, gender, customer segments, age groups, occupations, and customer counts over time.

## Tools Used

- Microsoft Excel — data cleaning and preparation
- Microsoft Power BI — data modelling, analysis and dashboard development
- DAX — calculations and measures
- PowerPoint — dashboard background/design layer

## Dashboard Features

Interactive slicers:

- Region
- Gender
- Customer Segment
- Age Group

Main visuals:

- Customer Count by Region
- Average Age by Age Group
- Customer Count by Occupation
- Customer Count by Year
- Customer Segment Distribution
- Gender Distribution

The slicers interact with the dashboard visuals, allowing users to explore specific customer groups dynamically.

## Data Preparation

Customer data was cleaned and prepared before analysis in Power BI. The dashboard uses customer-level fields including CustomerID, Age, Age Group, Gender, Region, Occupation, Customer Segment, and Year.

## Observed Dataset Findings

The dashboard displays 75 customers in the gender and customer-segment distributions. Female customers account for 41 customers (54.7%), while male customers account for 34 customers (45.3%). Customer segments shown are Retail (45), Corporate (24), and Private (6).

These are descriptive findings for the dataset represented in this project and should not be treated as representative of a wider population without additional analysis.
